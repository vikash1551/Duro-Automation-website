# DURO Automation — Cinematic Walkthrough Website

A one-page, scroll-driven cinematic walkthrough of a smart villa. The visitor
walks through the home in one continuous camera journey — 14 connected stops —
with smart-home automation moments triggering in every space, and **true 3D
depth parallax**: every photo carries an AI-generated depth map, so near
objects slide past faster than far ones as the camera dollies forward.

Journey: Exterior → Gate → Hall → Corridor → Bedroom → Corridor → Kitchen →
Corridor → Bathroom → Corridor → Balcony → straight back to the Exterior with
the contact finale. Bedroom, Kitchen and Bathroom each walk back out to the
corridor (reverse walk-out) before moving on.

## Setup & Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Setup Environment Variables
```bash
# Copy the example env file
cp .env.example .env.local
```
Then open `.env.local` and replace with your MongoDB credentials:
```env
MONGODB_URI=mongodb+srv://YOUR_USERNAME:YOUR_PASSWORD@YOUR_CLUSTER.mongodb.net/duro-automation?retryWrites=true&w=majority
```

> **Get your MongoDB URI:** Go to [MongoDB Atlas](https://www.mongodb.com/atlas) → Create free cluster → Connect → Drivers → Copy connection string

### 3. Run the Project
```bash
npm run dev              # http://localhost:3000
npm run build            # production build
npm run optimize-images  # rebuild public/images from Downloads sources
```

## How it works

- The villa photographs live in `public/images`; their depth maps (bright =
  near) in `public/images/depth`, generated by Depth-Anything-V2 via
  transformers.js in `scripts/generate-depth.mjs`.
- `components/Scene.tsx` renders each photo as a full-screen WebGL layer with
  a custom depth-parallax shader: iterative depth reprojection (near pixels
  magnify/drift faster than far), a dolly toward each room's doorway, an
  organic portal opening that dissolves one room into the next, warm rim
  light, arrival blur and lights-fade-on brightness.
- Scroll is smoothed by Lenis, measured by GSAP ScrollTrigger, and mapped
  through **weighted segments** (`lib/journey.ts` — connector beats like the
  corridor are shorter walks) to a single progress value in `lib/store.ts`.
- Journey content (titles, chips, doorway targets, dolly/sway strength per
  room, transition captions) is data in `lib/journey.ts` — tune the walk
  without touching components. `minor: true` stops get the compact HUD.
- To swap in the real logo later, edit the wordmark in `components/Nav.tsx`
  and `components/Loader.tsx`.

## Tuning the camera feel

Per room in `lib/journey.ts`: `dollyScale` (how far the camera walks in),
`swayScale` (lateral drift), `baseZoom` (re-enter the same photo deeper —
used by corridor pass 2), `portal` (screen-space doorway target). Globals in
`components/Scene.tsx` timeline math.
